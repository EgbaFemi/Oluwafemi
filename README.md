### Linux Permissions Audit

**Objective:** Identify insecure file permissions and apply appropriate
access restrictions in a Linux lab environment.

**Method:** Inspect permissions, identify unnecessary access, apply
permission changes, and verify the resulting configuration.

**Supporting demonstration:** A disposable test file illustrates
detection of world-writable permissions and correction from `666`
to `640`.

**Skills:** Linux permissions, least privilege, security assessment,
and remediation validation.

### Phishing Email Investigation

**Objective:** Examine suspicious email indicators and document
recommended handling actions.

**Method:** Review sender information, reported SPF/DKIM/DMARC results,
and embedded URLs; document indicators and recommendations.

**Supporting demonstration:** A synthetic email illustrates
authentication-failure indicators and a sender/URL domain mismatch.
These indicators require contextual investigation.

**Skills:** Email header analysis, indicator assessment,
investigation, and incident reporting.

### Infrastructure Telemetry and Alerting

**Objective:** Evaluate operational readings and identify conditions
requiring attention.

**Method:** Process sample fuel and temperature readings, validate
fuel values, and evaluate alert thresholds.

**Supporting demonstration:** Synthetic site readings illustrate
alerts for fuel below 30% and temperature above 40°C, including
boundary checks and rejection of invalid fuel readings.

**Skills:** Python, data validation, monitoring logic,
and operational exception reporting.
